User data deletion

Last updated: 4 September 2026 · {{ app_name }} ({{ site_host }})

This page explains how to request deletion of personal data processed by this {{ app_name }} instance (including WhatsApp-related data).

What can be deleted

  • WhatsApp inbox photos and sender phone numbers stored for intake.
  • Invoice images and extracted fields tied to those messages, where still retained.
  • Allow-list entries that contain your phone number.

How to request deletion

  1. Email {{ contact_email }} with subject {{ app_name }} data deletion request.
  2. Include the WhatsApp number (with country code) used to send messages, and approximate dates.
  3. We will confirm and remove or anonymise matching records from this instance within 30 days, unless we must retain data for legal or security reasons.

Shop operators

If you operate this dashboard, you can also delete WhatsApp inbox items and invoices from the signed-in web app, and remove numbers under WhatsApp settings.
